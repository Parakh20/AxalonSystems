# Platform Modules Overview

- **api/**: Contains API endpoints for data ingestion, processing, and reporting.
- **config/**: Holds configuration files for platform settings.
- **core/**: Includes core components such as detectors, fusions, and geographic utilities.
- **db/**: Manages database models and session handling.
- **park/**: Contains functionality related to park localization and management.
- **pipeline/**: Orchestrates data ingestion, detection, and reporting processes.
- **reporting/**: Handles the generation of reports in various formats (PDF, Excel, GeoJSON).
