Three Approaches — Pick Your Architecture

The key decision: what powers the operator dashboard and client portal?

A

Streamlit-Only

Everything in Streamlit — upload, results, park map, client reports. One Python app, no frontend work.

Pros

  • Fastest to build
  • 100% Python
  • Works offline/locally

Cons

  • Not polished enough for client portal
  • Hard to multi-tenant
  • Limited UI control
B ★ Recommended

FastAPI + Streamlit + Report Delivery

FastAPI handles all processing. Streamlit is the operator tool. Clients get professional PDF/Excel delivered, with a simple read-only web view via FastAPI.

Pros

  • Clean separation of concerns
  • Scales to cloud without rewrite
  • Docker-ready from day 1
  • Operator + client needs met

Cons

  • Slightly more setup
  • Client portal is read-only initially
C

FastAPI + React Portal (reuse website)

Build the operator dashboard and client portal inside the existing React website. Full-stack monorepo — one polished product from day 1.

Pros

  • Best client experience
  • Single brand/product
  • Best long-term architecture

Cons

  • Most work upfront
  • React frontend dev needed
  • Overkill for local phase
