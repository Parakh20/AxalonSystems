# Repository Structure

- **website/**: Contains the Next.js frontend code for the marketing site.
- **ml/**: Houses the machine learning model and its associated utilities.
- **platform/**: Includes the backend API, database models, and platform-specific functionality.
- **tests/**: Holds the test suite for both the website and platform.
- **main.py**: The entrypoint for the CLI.
- **ml/requirements.txt** and **requirements_platform.txt**: Dependency files for ML and platform environments.
