# Dashboard Defect Map — Design Spec
Date: 2026-06-02

## Overview

A standalone `/dashboard` route on the Axalon Systems Next.js website. Displays a dummy AXA-9 mission report with two tabs: a block defect map (Shot 18) and an automated report/work-order view (Shot 19). Pure HTML/CSS — no R3F canvas. All data is hardcoded.

---

## Route & Files

| Path | Purpose |
|------|---------|
| `app/dashboard/layout.tsx` | Minimal layout — dark bg, no navbar |
| `app/dashboard/page.tsx` | Tab shell — renders BlockMapTab or ReportTab |
| `components/Dashboard/BlockMapTab.tsx` | Shot 18: grid + stats + defects list |
| `components/Dashboard/ReportTab.tsx` | Shot 19: email panel + work order panel |

---

## Design Tokens

Reuse existing site values:
- Background: `#08080f`
- Text: `#e8e8f0`
- Muted: `#6b6b80`
- Teal accent: `#00f0c8`
- Panel bg: `rgba(255,255,255,0.04)`
- Panel border: `rgba(255,255,255,0.08)`
- Font (UI labels): Space Grotesk
- Font (data/monospace): Space Mono (or `monospace` fallback)

Severity colors:
- Critical / red: `#e53935`
- Moderate / yellow: `#f5a623`
- Healthy / blue: `#1565c0`

---

## Page Shell (`page.tsx`)

- Full-viewport dark background
- Fixed top bar (height ~44px): monospace text left-aligned — `AXALON SYSTEMS  |  AXA-9 MISSION REPORT  |  BLOCK 04 – 15.2 MW  |  01 JUNE 2026`
- Tab switcher centered below top bar: two buttons — **BLOCK MAP** and **REPORT & WORK ORDER** — teal underline on active tab
- Fixed bottom bar (height ~36px): monospace — `GENERATED BY AXA-9 EDGE AI  |  JETSON ORIN NANO 8GB  |  IEC TS 62446-3 COMPLIANT`
- Tab content fills remaining viewport height between the two bars

---

## Block Map Tab

Three-column flex layout, full height, padded.

### Left — Panel Grid

- 40 columns × 18 rows = 720 cells
- Each cell represents 10 panels → 7,200 total
- Cell size: ~14×14px with 2px gap
- Colors:
  - 8 cells: red (`#e53935`) — critical hotspot
  - 21 cells: yellow (`#f5a623`) — moderate anomaly
  - 691 cells: blue (`#1565c0`) — healthy
- Red/yellow cells scattered at fixed positions (hardcoded indices, not random)
- Legend below the grid: three color swatches — HEALTHY / MODERATE ANOMALY / CRITICAL HOTSPOT

### Centre — Summary Stats

Monospace list, vertically centered:

```
TOTAL PANELS SCANNED      7,200
DEFECTS DETECTED             42
CRITICAL HOTSPOTS             8
BYPASS DIODE FAILURES        21
CELL CRACKS                  13
ESTIMATED YIELD LOSS        2.3%
MISSION DURATION        00:47:23
COVERAGE                   100%
```

Teal value color, muted label color.

### Right — Top Defects

Table with three rows, no outer border, row-separated:

| ID | Type | String | ΔT | Dot | Severity |
|----|------|--------|----|-----|----------|
| D-07 | HOTSPOT | STRING 07 | ΔT +24°C | 🔴 | CRITICAL |
| D-12 | DIODE FAILURE | STRING 12 | ΔT +18°C | 🔴 | CRITICAL |
| D-19 | CELL CRACK | STRING 03 | ΔT +11°C | 🟡 | MODERATE |

All monospace. Severity dot is a colored inline circle element.

## Implementation Notes

- No state management beyond `activeTab` (useState)
- Grid cell positions for red/yellow hardcoded as index arrays — not randomized
- No animations required
- Mobile: single column stacked, grid scrolls horizontally
- No routing beyond the page itself
